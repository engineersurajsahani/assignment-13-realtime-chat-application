# Assignment 13: Real-Time Group Chat & Messaging Engine (Socket.io)

A multi-room real-time chat application built with Node.js, Express, and Socket.io.

## Features
- Multi-room switching (`#general`, `#developers`, `#random`)
- Real-time group messaging & history replay (last 50 messages)
- Active room user roster & online presence tracking
- Debounced typing indicators (`typing:start`, `typing:stop`)
- Direct private messaging to specific connected users
- Dark-themed responsive web client
